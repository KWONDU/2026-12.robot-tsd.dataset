## 읽는 법

- 각 샘플은 **입력**(유저 입력 + 환경 컨텍스트)과 **작업상황설명문**으로 구성됩니다. 추론 과정 원문은 jsonl의 intermediate.reasoning 필드에 있습니다.
- 작업상황설명문은 4개 필드로 구성됩니다: 작업 목표 / 시간·공간 조건 / 대상 물체 / 제약 사항.
- 대상 물체는 3분류입니다: 필수 물체(반드시 조작해야 하는 대상) / 선택 가능한 핵심 수단(목표 달성 수단, 대안이 있으면 함께 표기) / 보조 물체(위치 기준·참조용).
- 환경 컨텍스트의 id(obj_001, fx_* 형태)는 정답 누출 방지를 위해 중립화된 식별자입니다. 원래 물체 이름과 태스크명은 모델에 제공되지 않습니다.
- 검수는 규칙 기반(스키마 검증 / 접지 검사 / 구조 검사)과 LLM 교차 검수(체크리스트 5항목, 정보 충분성 probe, 각 0점부터 2점)를 함께 사용합니다. 체크리스트 judge는 생성 모델과 다른 모델이 맡습니다.
